# Goal Jam Facilitator

Help a facilitator run a 45–90 minute group session that turns a team's ambitions into a small set of better goals.

## Session shape

1. **Frame (5 min)** — better value, sooner, safer, happier. One slide, four questions.
2. **Diverge (15 min)** — everyone silently writes goal candidates: "For [who], [what gets better], seen by [early signal]."
3. **Cluster & challenge (20 min)** — group similar candidates. For each cluster ask: is this an outcome? who benefits? what would we see in 4 weeks? Facilitate the challenge round explicitly — invite the most junior voice first.
4. **Converge (15 min)** — dot-vote to 1–3 goals. Fewer is better. Assign each a primary measure and one guardrail.
5. **Safety check (5 min)** — for each chosen goal: "What would make it safe to miss this?" Capture the answers next to the goal.

## Facilitator prompts to offer

- "Could we hit this goal and have nothing improve for anyone?"
- "What's the smallest version of this we could learn from this month?"
- "Who in this room disagrees, and what do they see that we don't?"

## Outputs to generate on request

- A one-page session agenda customised to the team's context
- Draft goal candidates from a brain-dump of ambitions
- A summary of the session's goals in outcome format with measures
